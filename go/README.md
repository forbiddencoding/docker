# Golang with Live-Reloading

![Golang](https://img.shields.io/badge/-Golang-informational?style=for-the-badge&logo=go&logoColor=00ADD8&color=27272A)

Golang Docker setup with live-reloading with [cosmtrek/air](https://github.com/cosmtrek/air).

## Commands

Every command can be found inside the [Makefile](Makefile).

> [!NOTE]
> The usual Docker and Docker Compose commands can still be used.

| Command | Description                            |
|:--------|:---------------------------------------|
| `up`    | starts container for local development |
| `down`  | stops container in local development   |
